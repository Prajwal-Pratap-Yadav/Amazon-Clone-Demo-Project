# Privacy and scope

The application stores only versioned product IDs and quantities in browser-local storage. Remove items, complete the fictional checkout or clear site data to erase the cart. Browsers can block or evict storage; the interface explains its in-memory fallback.

Checkout accepts fictional details. Fields remain in page memory until completion or dialog dismissal; they are never sent or saved. There are no accounts, payments, analytics or third-party runtime scripts. The source link navigates to GitHub only when clicked.

This is an educational interface, not a merchant. Do not enter real personal information or interpret confirmation as an actual order.
