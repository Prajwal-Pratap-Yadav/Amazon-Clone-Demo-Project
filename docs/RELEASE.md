# Everyday storefront 0.1.0 engineering preview

An educational native-DOM storefront with synthetic products, original SVGs, bounded saved cart and fictional checkout. No real accounts, orders or payments; not affiliated with or endorsed by Amazon.

Requires Node 24 for development. Clone, `make setup`, then `make run`; open the repository subpath. Release artifacts include the tested static bundle, recorded measurement files and SHA-256 checksums. Evidence, tools and source commits are recorded in docs/EVIDENCE.md.

Known limits: synthetic local lab workload, Chromium-only automation, no complete manual WCAG/screen-reader review and no field telemetry. Historical assets lack rights provenance and are absent from this build; original source/history remains preserved.
