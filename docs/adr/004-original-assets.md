# ADR 004: generate original local illustrations

Accepted, 2026-10-04.

The original logo and product photographs had no recorded rights provenance and broken references. Shipping them again would preserve neither a working catalog nor a reproducible asset source.

Use original geometric SVG drawings generated by `scripts/generate_assets.mjs`, with local paths, explicit dimensions and lazy loading for catalog images. The generator is formatted deterministically and requires no external image service. [ASSETS](../ASSETS.md) records current and historical provenance.

Alternative: licensed photographs could show physical products more clearly, but would need individual provenance and download checksums. A third-party image CDN would also introduce network dependence. Neither is needed for this synthetic interaction study.

The trade-off is that illustrations do not document real products. The interface and data explicitly label the collection as imaginary. Historical assets remain in existing Git history; original HTML/CSS are preserved separately.
