# Contributing

Use Node 24, npm, Make and Python 3. Run `make setup-dev`, then `make lint typecheck test test-e2e docs security`. `make reproduce` saves actual browser reports under `reports/local`; preserve the original baseline. Stage named paths and review `git diff --cached`. The installed staged hook scans secrets; `.pre-commit-config.yaml` supports the same check for users of the pre-commit framework.

Preserve original legacy bytes and license. Use synthetic data and original or clearly licensed artwork. Prices remain integer paise and saved state is untrusted input. Do not add personal data, tracking or real payments. Describe measured scope and limitations, and add meaningful tests for behavior changes.
